# Governance

relaybay is a single-maintainer project.

- **Decisions.** The maintainer decides what is merged and released. Larger changes start as an
  issue or a discussion so the approach can be agreed before code is written; design decisions are
  recorded in [docs/design/](docs/design/index.md) and [docs/adr/](docs/adr/).
- **Roadmap.** The plan is public in [docs/ROADMAP.md](docs/ROADMAP.md). Ideas and requests are
  welcome in GitHub Discussions (Ideas) or as feature requests; the maintainer's own workflow sets
  the order first.
- **Releases.** Semantic Versioning; every release is a `v*` tag with notes from
  [CHANGELOG.md](CHANGELOG.md).
- **Conduct.** Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
- **Security.** Vulnerabilities are reported privately, see [SECURITY.md](SECURITY.md).

If the project gains regular contributors, this note will describe how maintainers are added.
