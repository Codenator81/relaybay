Permission profiles

What a run's turns start with: the permission mode, the allowed and the taken-away tools. Every turn reads its run's profile when it starts, so an edit takes effect on the next turn of every run that uses it, and the turn records the profile's version. A run whose mode was picked on its Start form or changed between turns keeps that mode; its tools still follow the profile. A project's agent defaults on Stands & access name the profile for its cards.
