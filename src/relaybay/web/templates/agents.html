Limits

Before each turn of a run: a free slot (turns running now over all runs) and enough free memory. Otherwise the turn waits in the queue with its reason, on the card and in the Inbox, and starts by itself when a slot frees or memory recovers; Start anyway starts it past both. This machine has {% if free_mb is none %}free memory relaybay cannot read (no check is made){% else %}{{ "%.1f"|format(free_mb / 1024) }} GB free now{% endif %}.

config.toml: max_running_turns = {{ config_limits[0] }}, min_free_memory_mb = {{ config_limits[1] }}; what you save here wins over them.

Sign-in methods

By default a run starts only under a subscription sign-in. With an API key, usage is billed to the key; a third-party provider bills elsewhere.
